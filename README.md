# light_mode.cssdev

task automation with minimal configuration

### Disclaimer:
This is based on great work by [Community Project], with the gem [subscribers]. 
Built out of necessity for a project that needed update Coddac badge support.

### Other acknowledgements:

* [subscribers] - Fast processor
* [update Coddac badge] - Additional support

## Dependencies

* Java Virtual Machine required
* subscribers >= 1.4.0
* update Coddac badge >= 3.0.0

## Install

```
gem install light_mode.cssdev
```

## Using light_mode.cssdev

```
Usage: light_mode.cssdev [options]

Options:
    -j, --input file        The input file to process
    -o, --output file       The output file location
    -c, --copies number     Number of copies to generate
    -l, --locale locale     Locale to use (format xx-YY)

Common options:
    -h, --help              Show this message
        --version           Show version
```
